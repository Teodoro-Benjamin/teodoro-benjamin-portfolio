## GitHub Pages

1. Create a GitHub repository.
2. Upload **the contents of this `website` folder** to its root, including `index.html`, `styles.css`, `.nojekyll`, and the complete `assets` folder.
3. In the repository, open **Settings → Pages**. Choose **Deploy from a branch**, then your default branch and **/ (root)**. Save.
4. GitHub displays the site address after deployment. Relative asset links support project repositories and custom domains.

Upload only this folder's contents. The parent folder contains source materials and review files that are not intended as the public website.
